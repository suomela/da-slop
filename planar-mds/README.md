# Planar dominating set approximation

## Context

Minimum dominating set in finite simple planar graphs, in the deterministic LOCAL model.

## New result

There is an $O(1)$-round deterministic algorithm with approximation ratio **exactly 7**.

## Prior work

[Hilke, Lenzen, and Suomela, PODC 2014](https://arxiv.org/abs/1402.2549) rule out a deterministic constant-round $(7-\varepsilon)$-approximation for every $\varepsilon>0$.

[Amiri and Siebertz 2026](https://arxiv.org/abs/2610.09618) and [Picavet 2026](https://arxiv.org/abs/2610.31203) give a $(7+\varepsilon)$-approximation for every fixed $\varepsilon>0$.
